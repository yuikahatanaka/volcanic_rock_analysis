# Volcanic Rock Geochemical Analysis

This project analyses geochemical data from volcanic mineral samples to understand 
differences between Core, Mantle, and Rim zones. The notebook includes data cleaning, 
feature exploration, and interpretation of geochemical patterns.

## Contents
- `analysis.ipynb` — main notebook with all code and visualisations
- `data/` — optional sample dataset (if included)

## What I did
- Cleaned and explored geochemical features (EMPA + Laser Ablation)
- Analysed patterns across Core / Mantle / Rim zones
- Visualised relationships between major and trace elements
- Interpreted mineral zoning behaviour from geochemical signatures

## Skills demonstrated
- Python (NumPy, pandas, Matplotlib)
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Scientific interpretation and documentation

## What I learned
- How geochemical features vary across mineral zones
- How to structure a scientific analysis in Python
- How to interpret patterns in real-world scientific datasets
